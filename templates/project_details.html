Prisoner's Dilemma Evolution Simulation

Made by ET

Project Overview

This project simulates the evolution of different strategies in the Prisoner's Dilemma game over multiple generations. The simulation models how different behavioral strategies compete, reproduce, and evolve based on their performance in iterated games.

Background: The Prisoner's Dilemma

The Prisoner's Dilemma is a classic game theory scenario where two players must choose between cooperation and defection. The payoff structure creates a tension between individual rationality (defecting) and collective benefit (cooperating).

In this simulation, we explore how different strategies evolve when players interact repeatedly and their reproductive success depends on their accumulated payoffs.

Available Strategies

Always Cooperate

This strategy always chooses to cooperate, regardless of the opponent's previous actions. It represents unconditional cooperation.

Always Defect

This strategy always chooses to defect, regardless of the opponent's previous actions. It represents unconditional defection.

Tit-for-Tat

This strategy starts by cooperating, then copies the opponent's last move in subsequent rounds. It is known for being both nice (starts cooperatively) and retaliatory (responds to defection).

Grudge

This strategy cooperates until the opponent defects once, then permanently switches to defection for the remainder of the encounter. It forgives nothing once betrayed.

Prober

This strategy mostly cooperates but occasionally defects during long sequences of mutual cooperation. It "probes" the opponent's response to defection while generally maintaining cooperation.

Random

This strategy makes random choices between cooperation and defection each round, with equal probability.

Simulation Parameters

Initial Population (N₀)

The starting number of agents in the simulation.

Strategy Proportions

The initial distribution of strategies in the population. These values must sum to exactly 1.0. You can set a proportion to 0 to exclude a strategy from the initial population.

Payoff Matrix

The payoff values for different action combinations:

  • CC (Both Cooperate): Reward (R) - typically the second-highest payoff
  • CD (You Cooperate, Opponent Defects): Sucker's Payoff (S) - typically the lowest payoff
  • DC (You Defect, Opponent Cooperates): Temptation (T) - typically the highest payoff
  • DD (Both Defect): Punishment (P) - typically the second-lowest payoff

For a valid Prisoner's Dilemma, the payoffs must satisfy: T > R > P > S and typically 2R > T + S.

Total Generations (G)

The number of generations to simulate.

Recording Interval (T)

How often (in generations) to record and display the population state.

Rounds per Encounter (R)

The number of Prisoner's Dilemma rounds each pair of agents plays when they meet.

Selection Percentile (Y%)

The bottom Y% of agents (by accumulated score) are eliminated each generation. The remaining survivors reproduce to form the next generation.

Offspring per Survivor

Each surviving agent produces this many offspring in the next generation. Note: This means the population size can change over time.

Mutation Rate (Z)

The probability that an offspring will have a random strategy instead of inheriting the parent's strategy. This introduces genetic diversity into the population.

How the Simulation Works

Generation 0 (Initialization)

The population is created with the specified initial size and strategy proportions. This state is recorded as generation 0.

For Each Generation (1 to G):

  1. Reset Scores: All agents' scores are reset to 0.
  2. Random Pairing: Agents are randomly paired (if odd population, one agent sits out).
  3. Play Encounters: Each pair plays R rounds of Prisoner's Dilemma according to their strategies. Scores accumulate based on the payoff matrix.
  4. Selection: The bottom Y% of agents (by score) are eliminated.
  5. Reproduction: Each survivor produces X offspring (where X is "Offspring per Survivor"). Each offspring has a Z% chance of mutation (random strategy).
  6. Recording: If this generation is a multiple of the recording interval, the population composition is recorded.

Visualization

The simulation provides two main visualizations:

  • Population Over Time: A stacked line chart showing how the population of each strategy changes across generations.
  • Final Proportions: A bar chart showing the final distribution of strategies at the end of the simulation.

Technical Details

This simulation is built using:

  • Backend: Python with Flask for the API server
  • Frontend: HTML, CSS, and JavaScript with Chart.js for visualizations
  • Optimization: Numba JIT compilation for efficient computation of large simulations

Interpreting Results

When analyzing simulation results, consider:

  • Which strategies survive and thrive in the long term?
  • How do different payoff matrices affect strategy evolution?
  • What role does mutation play in maintaining diversity?
  • How does the selection pressure (Y%) affect outcomes?
  • What happens when population size changes over time?
